# Corpfiaca

> Uma plataforma corporativa moderna desenvolvida com Next.js

## 📋 Sobre o Projeto

Corpfiaca é uma aplicação web corporativa desenvolvida com Next.js 15, React 19 e TypeScript. O projeto inclui funcionalidades completas para um site corporativo moderno, incluindo portfólio, blog, serviços, carreiras e muito mais.

## 🚀 Tecnologias Utilizadas

- **Framework:** Next.js 15.5.3
- **Linguagem:** TypeScript
- **Frontend:** React 19.1.0
- **Estilização:** Bootstrap 5.3.7
- **Animações:** GSAP 3.13.0
- **Componentes Interativos:** Swiper, Chart.js, SweetAlert2
- **Desenvolvimento:** Turbopack para build e dev

## 🛠️ Instalação e Configuração

### Pré-requisitos

- Node.js (versão 18 ou superior)
- npm, yarn, pnpm ou bun

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/mrdouglasmorais/corpfianca.git
cd corpfianca
```

2. Instale as dependências:
```bash
npm install
# ou
yarn install
# ou
pnpm install
```

3. Execute o servidor de desenvolvimento:
```bash
npm run dev
# ou
yarn dev
# ou
pnpm dev
# ou
bun dev
```

4. Abra [http://localhost:3000](http://localhost:3000) no seu navegador.
